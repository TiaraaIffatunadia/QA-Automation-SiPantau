# BDD Automated Black-Box Testing: Web Monitoring System

## Overview
This is my bachelor's thesis project. I automated functional tests for a
web-based monitoring system using BDD (Behavior-Driven Development).

## Results
- 560 test cases executed
- 94 functional failures found across modules
- 50.5% less testing time than manual testing

## Test Design Techniques
- Equivalence Partitioning (EP)
- Boundary Value Analysis (BVA)
- Decision Table (DT)
- Basic security checks: access control and session management

## Tools
Katalon Studio (Selenium-based), Cucumber/Gherkin, Groovy, GitHub

## My Role
Test planning, test case design, writing Gherkin scenarios, running
automated tests, and reporting bugs.

## Note
The tested system requires login and is not public, so only sanitized
samples are included in this repo.

## Limitations and Next Steps
This project covers functional testing only. I am now learning regression
testing and API testing (Postman).
