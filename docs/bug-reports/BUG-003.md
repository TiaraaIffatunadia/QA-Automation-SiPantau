# BUG-003: System accept a negative value in the budget realization field

- **Module:** Financial Realization Module
- **Role:** User Bidang
- **Technique:** BVA
- **Related to:** SC-145

## Steps to reproduce
1. Log in as User Bidang
2. Click "Monitoring Report" menu
3. Click "Verification" button
4. Click "Set Status" button
5. Click "Edit" button
6. Enter "-1" in the budget realization field
7. Click "Send" button

## Expected result
The system rejects values below 0 in the budget realization field

## Actual result
The system accepts the values "-1" in the budget realization field
