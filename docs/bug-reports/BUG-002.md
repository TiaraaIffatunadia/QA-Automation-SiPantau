# BUG-002: User can select a job type outside their authority area

- **Module:** Module Form Edit Realisasi Pekerjaan
- **Role:** User KCD
- **Technique:** DT
- **Related to:** SC-043

## Steps to reproduce
1. Log in as User KCD
2. On the Dashboard, click "Detail" button
3. Click "Add Work" button
4. Select "USB SMA" in the job type field
5. Enter "1" in the work volume field and "1000000" in the total budget field
6. Click "Save" button

## Expected result
The system only allows the user select job types within their authority area

## Actual result
The system allows the user select job type outside their authority area
