# BUG-001: System accepts lower progress value when editing work realization

- **Module:** Module Form Edit Realisasi Pekerjaan
- **Role:** User Sekolah
- **Technique:** EP
- **Related to:** SC-019

## Steps to reproduce
1. Log in as School User
2. Click "Realization Menu"
3. Click "Add Realization" button
4. Fill form add work realization with a progress value of 50% and a valid document
5. Click "Submit" button
6. Select the work realization you just created
7. Click "Edit Realization" button
8. Edit the progress value to 40% and upload a valid document
9. Click "Save" button

## Expected result
The system rejects the change and shows an error message,
because progress cannot decrease

## Actual result
The system saves the progress value of 40%
